# Simple Interest Calculator

A simple calculator to calculate Simple Interest.

## Formula

Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time

## Example

If:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100

## Features

- Easy to use
- Calculates simple interest quickly
- Simple and beginner-friendly project
